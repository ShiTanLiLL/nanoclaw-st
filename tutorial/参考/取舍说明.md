# 原项目与教学项目的取舍说明

## 保留的核心

| 原项目能力 | 教学项目计划 | 保留理由 |
|---|---|---|
| 消息进入 → 回复投递的 Happy Path | 保留，分课实现 | 这是用户能感知的核心业务 |
| 触发词/mention 与不触发消息 | 保留简化版 | 体现渠道消息不是都要唤醒 Agent |
| 会话上下文与恢复 | 保留 | 能说明内存、文件、数据库为何演化 |
| 多聊天到多会话路由 | 保留简化版 | 体现数据隔离和 Session 身份 |
| 异步处理、消息状态、重试 | 保留主干 | 解释真实运行时的可靠性 |
| 中心 DB 与 per-session 双邮箱 | 保留核心思想 | 原项目最有教学价值的工程机制 |
| 容器隔离和挂载边界 | 保留最小可运行版本 | 体现 NanoClaw 的安全选择 |
| Provider 替换、一个真实模型 + 测试替身 | 保留 | 解释抽象为什么晚出现 |
| 任务调度、文件、安全边界 | 保留压缩版 | 对应重要能力和状态流 |

## 主动省略或压缩的内容

| 原项目内容 | 教学处理 | 删除后损失为何可接受 |
|---|---|---|
| 20 多次中心 DB migration、远程 DB driver、组合式 mailbox | 只保留少量从零建表/迁移 | 学生先理解数据与单写者，不需学习兼容历史 |
| 全部渠道（WhatsApp、Slack、Telegram、Discord、Teams、Linear、GitHub 等） | 最终只实现终端/文本重放，不接外部平台 | 平台 SDK 差异不是核心路由心智模型 |
| Chat SDK 全部卡片、订阅、线程能力 | 保留最小消息往返思想，不实现平台线程 | 避免把平台能力误认为业务核心 |
| OneCLI 全部凭据、审批和 portal 流程 | 用安全边界案例解释，必要时做最小接口 | 真实凭据服务需要外部账号，超出初学阶段 |
| Agent-to-Agent、跨 session context、skills 自修改 | 只在最终对照中说明或选一小段 | 不是普通 Happy Path 的前置条件 |
| setup wizard、迁移 v1/v2、社区 portal、发布脚本 | 只记录部署边界 | 主要是运维与产品流程，不推动核心业务 |
| 大量极端兼容和安全兜底 | 选择附件路径、幂等和重试的代表案例 | 保留安全思维但控制学习曲线 |
| 全部 provider（Claude、OpenCode、Ollama 等） | 先一个真实 Provider + 一个测试替身 | 第二实现出现时再抽象最清楚 |
| 完整 CLI `ncl` 资源体系 | 最后实现只读状态/最小管理命令 | 先理解业务再学习管理面 |

## 不复制的最终架构

第一课不会出现 `ChannelAdapter`、`Provider`、`Repository`、`SessionManager`、
`Mailbox` 或 Docker。它们只有在对应需求使当前代码变得困难时才进入项目。允许
后续课程移动、拆分、重写早期文件；这种破坏和重组本身就是课程目标。

## 第 10 课的具体取舍

保留实际 Docker 隔离与只读/可写挂载，使用与宿主相同的 Node 运行处理器，
不照搬原项目的 Bun 工具链。容器处理一轮后退出，宿主直接等待结束，因此
暂省略常驻轮询、心跳、容器池与重启策略；损失是不能作为后台长驻 Agent，
但不影响本课验证邮箱跨容器交接与文件权限边界。

## 第13课的具体取舍

原项目任务属于Agent群组，使用独立系统会话和cron，可有脚本门控与目的地投递。
教学版保存中央任务表，使用一次时间戳或固定毫秒间隔，到期复用已有聊天绑定、
会话记忆和邮箱。损失是没有独立任务上下文、日历式cron、取消/暂停、自动恢复
与频率门控；保留“未来输入持久化→到期消息链→确认与下轮”的核心演化。
明确仅一个宿主扫描进程，正常重复扫描不重发不等于故障下恰好一次。

## 第14课的具体取舍

保留原项目有限退避、输入/输出确认与路径安全思想。教学版用中央接收凭据、
稳定任务轮次ID、入站唯一source_key复用原快照，代替完整claim/驱动/心跳体系；
文件只做宿主16KiB UTF-8文本读取与快照，不做文件平台上传/下载或任意工具访问。
省略跨进程抢占、独立任务系统会话、平台幂等键、断电容错与完整安全治理。
API成功/响应丢失、stdout输出/确认未写等仍可重复，不承诺绝对恰好一次。

## 第15课最终取舍

保留配置有效性、只读统计、固定事件日志和本地所有者的周期审批/暂停。
不照搬原项目CLI资源体系、平台权限与OneCLI审批。旧周期任务仍pending，
新周期登记才待审批；审批不是多用户认证，不取消在途请求。只提供可信用户
单宿主前台部署说明，不安装服务或执行云端部署。处理器不变，继续lesson14镜像。
原规划中的平台/线程例子最终主动省略：没有新的真实平台接入需求，不为结课
引入账号与SDK复杂度。完整能力与省略边界见最终心智模型，教学实现非原项目副本。
