# 数据模型

## 原项目中心数据库

| 数据 | 关键字段 | 产生者 | 读取/改变者 | 教学价值 |
|---|---|---|---|---|
| users | `id`, `kind`, `display_name` | 权限/发送者解析 | Router、权限模块 | 说明平台身份不能只用昵称 |
| agent_groups | `id`, `name`, `folder` | 设置/CLI | Router、容器运行器 | 一套工作区和技能 |
| messaging_groups | `channel_type`, `platform_id`, `instance`, `is_group` | Router/设置 | Router、Delivery | 一个真实聊天地址 |
| messaging_group_agents | `messaging_group_id`, `agent_group_id`, `engage_*`, `session_mode` | 设置/CLI | Router | wiring：为什么该 Agent 收到消息 |
| sessions | `agent_group_id`, `messaging_group_id`, `thread_id`, 状态 | Session Manager | Runner、Sweep、Delivery | 连续上下文和容器身份 |
| pending_* | question/approval 映射 | Delivery/模块 | 交互响应处理 | 低频但重要的分支 |

## 原项目每会话邮箱

### inbound.db（宿主写入）

```text
messages_in(
  id, seq, kind, timestamp, status, process_after, recurrence,
  trigger, platform_id, channel_type, thread_id, content,
  source_session_id, on_wake
)
delivered(message_out_id, platform_message_id, status, delivered_at)
destinations(name, type, channel_type, platform_id, agent_group_id)
session_routing(id=1, channel_type, platform_id, thread_id)
```

### outbound.db（容器写入）

```text
messages_out(
  id, seq, in_reply_to, timestamp, deliver_after, recurrence,
  kind, platform_id, channel_type, thread_id, content
)
processing_ack(message_id, status, status_changed)
session_state(key, value, updated_at)
container_state(current_tool, tool_declared_timeout_ms, tool_started_at, updated_at)
```

### 一个实际数据例子

入站：

```json
{
  "id": "msg-001:assistant",
  "kind": "chat",
  "platform_id": "room-42",
  "channel_type": "console",
  "thread_id": null,
  "content": {"text": "@Andy 总结今天的任务", "sender": "user-1"},
  "trigger": 1
}
```

出站：

```json
{
  "id": "msg-002",
  "kind": "chat",
  "in_reply_to": "msg-001:assistant",
  "platform_id": "room-42",
  "channel_type": "console",
  "content": {"text": "今天完成了……"}
}
```

## 教学项目的数据演化

| 阶段 | 数据形态 | 为什么现在够用 |
|---|---|---|
| 第 1 课 | 一个 `string` 输入和一个 `string` 输出 | 只有一个本地调用者和一次回复 |
| 第 2 课 | 文本 + 是否触发的判断 | 只增加触发需求，不需要消息表 |
| 第 3 课 | 内存中的消息数组 | 只需要同一进程上下文 |
| 第 4 课 | JSON 文件中的会话 | 重启恢复首次出现 |
| 第 5 课 | `channelId → session` 映射 | 多聊天隔离出现 |
| 第 8 课 | SQLite 行 | 查询/并发使 JSON 方案不够 |
| 第 9 课 | 每会话 inbound/outbound 表 | 进程边界需要单写者 |
