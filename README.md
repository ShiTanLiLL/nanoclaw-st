# NanoClaw 渐进式复现项目

这是一个按需求逐课重新发明 NanoClaw 核心链路的教学项目，不是原项目的副本。

第 1 课建立最小单次对话链；第 2 课增加 `@Andy` 触发判断。当前第 3 课允许
在同一个进程中连续输入多行，并在内存中记住已经触发的用户正文。
课程资料位于 [`tutorial/`](./tutorial/)；最高优先级规则记录在工作区上级传入的
规范文件中，并由 [`工作守则.md`](./工作守则.md) 摘要维护。

## 当前运行

需要 Node.js 22+ 和 pnpm 10+。依赖安装后：

```bash
pnpm test
printf '@Andy 我叫小李\n大家下午三点开会\n@Andy 我刚才说了什么？\n' | pnpm start
```

普通聊天不会产生助手回复。当前历史只在一个进程的内存中，进程结束即消失；
项目不会调用网络、模型或 Docker。
